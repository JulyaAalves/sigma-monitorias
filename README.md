# SIGMA

**Sistema Integrado de Gestão de Monitorias Acadêmicas**

Projeto desenvolvido como Trabalho de Conclusão de Curso (TCC) do Bacharelado em Sistemas de Informação.

## Objetivo

Desenvolver uma plataforma web para gerenciamento das monitorias acadêmicas do IFMG, permitindo o cadastro de monitorias, envio e acompanhamento da documentação mensal, controle de prazos, notificações automáticas por e-mail e geração de relatórios.

## Tecnologias

- Python
- Django
- MySQL (ou SQLite durante o desenvolvimento)
- Bootstrap

## Funcionalidades previstas

- Login de usuários
- Controle de perfis (Monitor, Professor e Pedagogo)
- Cadastro de monitorias
- Upload de documentos
- Aprovação de documentos
- Controle de prazos
- Notificações por e-mail
- Dashboard
- Relatórios
